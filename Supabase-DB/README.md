# Team Database Setup Guide (Supabase)

This guide walks every developer through setting up access, local environment variables, and running database migrations for our project.

---

## 🛠 Prerequisites

1. **Node.js** (v18 or higher) installed.
2. **Git** installed.
3. Access to our team's **Supabase Project**. (Contact DevSecOps if you haven't received an invitation email).
